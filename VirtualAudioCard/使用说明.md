# Android虚拟声卡使用说明

## 概述

这个Android应用实现了虚拟声卡功能，可以拦截和处理微信的语音输入输出，实现音频增强、降噪、变声等功能。

## 实现原理

### 1. 虚拟音频设备
- 使用AudioRecord捕获麦克风输入
- 使用AudioTrack播放音频输出
- 在中间插入音频处理逻辑
- 模拟真实的音频设备行为

### 2. 音频拦截方式

#### 方案A: 无障碍服务 (推荐)
```
微信 → AccessibilityService监听 → 音频重定向 → 虚拟设备 → 音频处理 → 实际设备
```

#### 方案B: Xposed Hook (需要Root)
```
微信 → AudioRecord/AudioTrack Hook → 虚拟设备 → 音频处理 → 实际设备
```

#### 方案C: 音频焦点劫持
```
微信 → AudioFocus请求 → 拦截并重定向 → 虚拟设备 → 音频处理 → 实际设备
```

### 3. 音频处理链

#### 输入处理 (麦克风 → 微信)
```
原始音频 → 噪音门限 → 高通滤波 → 语音增强 → 压缩器 → AGC → 微信
```

#### 输出处理 (微信 → 耳机)
```
微信音频 → 噪音抑制 → 语音清晰化 → 均衡器 → 音量控制 → 耳机
```

## 安装步骤

### 1. 编译应用
```bash
cd VirtualAudioCard
./gradlew assembleDebug
```

### 2. 安装APK
```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```

### 3. 授予权限
- 启动应用
- 授予录音权限
- 启用无障碍服务

## 使用方法

### 基本使用

1. **启动虚拟声卡**
   - 打开应用
   - 点击"启动虚拟声卡"
   - 确认状态显示"运行中"

2. **开始音频处理**
   - 点击"开始处理"
   - 调整处理参数（可选）

3. **使用微信**
   - 打开微信
   - 正常进行语音通话或发送语音消息
   - 系统会自动处理音频

### 高级配置

#### 音频参数调节
- **噪音门限**: -60dB到-10dB，控制噪音抑制强度
- **压缩比**: 1:1到10:1，控制动态范围压缩
- **语音增强**: 0%到100%，控制语音清晰度增强

#### 处理模式选择
- **输入模式**: 仅处理麦克风输入
- **输出模式**: 仅处理音频输出
- **双向模式**: 同时处理输入输出

## 技术细节

### 音频格式
- 采样率: 44100Hz (可配置)
- 位深度: 16位
- 声道: 单声道
- 缓冲区: 4096字节

### 处理算法

#### 噪音抑制
- 频谱减法算法
- 自适应噪音估计
- 实时噪音门限

#### 语音增强
- 预加重滤波
- 人声频段增强 (300Hz-3400Hz)
- 动态范围优化

#### 回声消除
- 自适应滤波器
- 延迟估计和补偿
- 双端语音检测

### 性能优化
- 使用原生C++实现核心算法
- AAudio低延迟API
- 多线程音频处理
- 内存池管理

## 故障排除

### 常见问题

1. **无法录音**
   - 检查录音权限
   - 确认麦克风未被其他应用占用
   - 重启虚拟声卡服务

2. **音频延迟过高**
   - 降低缓冲区大小
   - 使用AAudio API
   - 关闭不必要的音频处理

3. **微信无法检测到音频**
   - 启用无障碍服务
   - 检查音频路由设置
   - 确认微信版本兼容性

4. **音质问题**
   - 调整处理参数
   - 检查音频设备质量
   - 确认采样率匹配

## 限制和注意事项

### 系统限制
- Android 10+对音频权限有更严格限制
- 某些厂商ROM可能不兼容
- 需要用户手动启用无障碍服务

### 性能限制
- 实时音频处理消耗CPU资源
- 低端设备可能出现延迟或卡顿
- 电池消耗会增加

### 法律风险
- 音频拦截可能违反某些地区法律
- 请确保合规使用
- 仅用于个人学习和研究
